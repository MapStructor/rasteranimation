This viewer is built by Geodan Research. It shows the date of construction of buildings in the Netherlands, using the BAG data.

You can use the first slider to adjust the year to view the buildings which are build before that year.
The second slider will adjust the opacity of the background map.

The BAG data is served by EduGIS
The background map is OpenStreetMap data styled and served by Cloudmade

For more info:

Also the data is not always accurate, it does typically have the wrong construction years for buildings older than 1850. If the year is properly set to unknown it will show up on the map as a black building.
